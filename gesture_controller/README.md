# Hand Gesture Controller

This project allows you to control your mouse cursor and click using hand gestures captured by your webcam.

## Prerequisites

- Python 3.7+
- A webcam

## Installation

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main script:
```bash
python main.py
```

## Controls

- **Move Mouse**: Move your index finger. The cursor maps to the position of your index finger tip.
- **Left Click**: Pinch your index finger and thumb together.
